# Primo CS Nam — Static Hosting Bundle

This bundle contains the static landing page files ready for **GitHub Pages**.

## Contents
- `index.html` — Product landing page for Primo CS Nam (VST3 / Standalone)
- `.nojekyll` — Disables Jekyll processing on GitHub Pages for faster, direct static deployment

## Before Publishing
Open `index.html` and replace `#gumroad-full` and `#gumroad-demo` with your live Gumroad product/variant URLs once created.
